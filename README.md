##  Projetos

###  Desafio-Sistema-Bancário
Sistema bancário em Python com operações de depósito, saque e extrato. Primeira versão desenvolvida com programação procedural, focada na lógica de negócio e controle de fluxo.

**Funcionalidades:**
- Depósito, saque com limite diário e extrato
- Controle de número máximo de saques por dia
- Validações de saldo e limites

---

###  Otimizacao_Sistema_Bancario_POO
Refatoração completa do sistema bancário utilizando **Programação Orientada a Objetos**. Demonstra a evolução natural de um código procedural para uma arquitetura mais robusta, escalável e reutilizável.

**Conceitos aplicados:**
- Classes, herança e encapsulamento
- Separação de responsabilidades
- Reutilização de código via POO

---

###  Codificando-com-Copilot
Projetos desenvolvidos com auxílio do **GitHub Copilot**, explorando como a IA pode aumentar a produtividade no desenvolvimento, sugerir boas práticas e acelerar a escrita de código.

---

##  Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/Thiiagoramos/Python-Projects.git
cd Python-Projects
```

2. Navegue até o projeto desejado e execute:
```bash
# Sistema Bancário procedural
python Otimizacao_Sistema_Bancario.py

# Sistema Bancário com POO
python Otimizacao_Sistema_Bancario_POO.py
```

> Os projetos dentro de `Codificando-com-Copilot` possuem instruções individuais em suas respectivas pastas.
